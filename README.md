# Week-3-Module-1-Password-Security-Testing-with-John-the-Ripper
Batch: B084
Week: 3
Module: 1
Project: Password Security Testing with John the Ripper (JTR)

Project Overview	
This project focuses on understanding password security testing using John the Ripper (JTR), a popular password auditing tool used by cybersecurity professionals.
The practical exercise explored how password auditing helps identify weak password practices and evaluate password strength as part of an authorised security assessment.

Objectives
•	Understand the fundamentals of password security.
•	Introduction to John the Ripper (JTR).
•	Explore password auditing concepts.
•	Understand how weak passwords can affect system security.
•	Learn the importance of strong password policies.

Tools Used
•	John the Ripper (JTR)
•	Kali Linux
•	Linux Terminal

Key Learning Outcomes
Through this practical module, I gained a better understanding of:
1.	Password security and authentication.
2.	Password auditing concepts.
3.	The importance of strong passwords.
4.	Common password security weaknesses.
5.	Security best practices for protecting user accounts.

Ethical Considerations
All practical activities were conducted within the authorised internship learning environment for educational and cybersecurity training purposes.
